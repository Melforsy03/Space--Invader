# 🎮 Space Invaders en Consola - Lenguaje C

Un clásico juego de Space Invaders implementado en lenguaje C para consola/terminal, utilizando caracteres ASCII para los gráficos.

## 🚀 Características

- **Gráficos ASCII** para naves y enemigos
- **Sistema de puntuación** en tiempo real
- **Múltiples niveles** de dificultad
- **Movimiento fluido** de enemigos
- **Sistema de vidas** del jugador
- **Pantalla de game over** con puntuación final

## 🎯 Controles

- **Flecha izquierda**: Mover nave a la izquierda
- **Flecha derecha**: Mover nave a la derecha
- **Barra espaciadora**: Disparar
- **ESC**: Salir del juego
